# LangChain Web Page Loader Explanation

Here is a step-by-step breakdown of how the web page loading and summarization code works:

---

### **1. Loading Environment Variables**
```python
from dotenv import load_dotenv

load_dotenv()
```
* **What it does:** Loads your external API keys (like `MISTRAL_API_KEY`) from your `.env` file into the environment so they can be read by the AI integration.

---

### **2. Importing the Libraries**
```python
from langchain_community.document_loaders import WebBaseLoader
from langchain_mistralai import ChatMistralAI
from langchain_core.prompts import ChatPromptTemplate
```
* **`WebBaseLoader`**: The loader class that fetches any web page URL, scrapes its HTML, and parses it into clean text.
* **`ChatMistralAI`**: Connects and communicates with Mistral AI models.
* **`ChatPromptTemplate`**: Formats the system guidelines and user prompt before sending it to the model.

---

### **3. Setting Up the AI Model**
```python
model = ChatMistralAI(model = "mistral-small-2506")
```
* **What it does:** Initializes the Mistral AI model (specifically `mistral-small-2506`) to be used for generating responses.

---

### **4. Scraping the Web Page**
```python
url = "https://en.wikipedia.org/wiki/Prompt_engineering"
data = WebBaseLoader(url)
docs = data.load()
```
* **`WebBaseLoader(url)`**: Points the scraper to the Wikipedia page on Prompt Engineering.
* **`data.load()`**: Sends an HTTP request to the webpage, downloads its HTML content, parses it using BeautifulSoup under the hood, and returns it as a list of LangChain `Document` objects containing the webpage text.

---

### **5. Structuring the Prompts**
```python
prompt = ChatPromptTemplate.from_messages([
    ("system", "you're AI that sums the text from web page"),
    ("human", "{data}")
])
```
* **`system`**: Instructs the AI what its persona/task is (e.g., *"you are an AI that summarizes the text from a web page"*).
* **`human`**: Sets up the placeholder `{data}` where we will insert the scraped webpage text.

---

### **6. Formatting the Inputs**
```python
prompt = prompt.format_messages(data = docs)
```
* **What it does:** Replaces the `{data}` placeholder inside the prompt template with your scraped webpage documents (`docs`). This compiles everything into a final list of messages ready for the AI model.

---

### **7. Invoking the Model and Printing Response**
```python
result = model.invoke(prompt)

print(result.content)
```
* **`model.invoke(...)`**: Sends the prompt with the scraped text to the Mistral AI API.
* **`result.content`**: Extracts and prints only the final text summary generated by the AI.
